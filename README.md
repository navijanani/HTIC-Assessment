# HTIC Assessment

This repository contains solutions for three questions.

## Question 1 — Imaging Science

Correct non-uniform illumination in grayscale and RGB images by separating the smooth illumination field from surface reflectance in the log domain.

## Question 2 — Computer Vision

Detect and order planar-grid corners, estimate camera distortion parameters robustly, and validate the result using reprojection error and undistorted-grid visualizations.


## Question 3 — Deep Learning

Train and evaluate a character-level PyTorch sequence-to-sequence model that transliterates Romanized Hindi into Devanagari.
